MUMMY EEMAN — BIRTHDAY WEBSITE

FILES
- index.html
- styles.css
- script.js

HOW TO USE
1. Keep all three files in the same folder.
2. Add the three real photos to this folder and name them exactly:
   photo-1.jpeg
   photo-2.jpeg
   photo-3.jpeg
3. Open index.html in a browser to preview.
4. To publish, upload the folder to your preferred static hosting service (such as Vercel, Netlify, or GitHub Pages).

DESIGN NOTES
- Luxury burgundy, champagne gold and warm cream palette.
- Slow scroll-triggered entrances, staggered photo reveals and gentle ambient motion.
- Interactive wish cards and candles.
- Optional original chime using Web Audio; it only plays after the visitor enables sound.
- Responsive layout and reduced-motion accessibility support.

You can replace the wording in index.html without changing the interactions.
